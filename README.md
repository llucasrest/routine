# Routine: rumo a uma vaga internacional de Senior Backend Engineer (Java)

Plano de 16 semanas, 1h por dia de segunda a sexta. Sábado é bônus opcional, domingo é livre.

**Meta:** vaga remota de Senior Backend Engineer (Java) em empresa dos EUA ou da Europa, de US$ 5.500 a 7.000/mês (mínimo para trocar: US$ 4.800; hoje: US$ 3.800).

## Como usar este repositório

1. Toda semana, abra o arquivo da semana em `semanas/` e marque as tarefas (`- [x]`) conforme concluir.
2. Segunda: escreva a nota da leitura em `notas/` usando o [template](notas/_template.md).
3. Sexta: registre candidaturas em [`carreira/candidaturas.md`](carreira/candidaturas.md) e histórias em [`historias-star/`](historias-star/).
4. No fim da semana, atualize o status na tabela abaixo (⬜ → 🟨 → ✅) e faça o commit: `git commit -m "semana 01: concluída"`.
