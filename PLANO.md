# Plano de carreira: vaga internacional Java Sênior

## Meta

Vaga remota de **Senior Backend Engineer (Java)** numa empresa dos EUA ou da Europa em 16 semanas, estudando 1h por dia de segunda a sexta.

| | Hoje | Meta |
| --- | --- | --- |
| Salário | US$ 3.800/mês | US$ 5.500 a 7.000/mês (mínimo para trocar: US$ 4.800) |
| Perfil | Dev Java sênior | Backend sênior Java com IA aplicada |

Referência de mercado: contractors brasileiros em empresas de fora recebem em geral entre US$ 3.000 e US$ 8.000/mês ([Numerando](https://www.numerando.com.br/blog/salario-desenvolvedor-software-brasil-2026)).

## Onde estou

**Pontos fortes:** 11 anos de Java; Broadridge (fintech) desde junho de 2025 com Java, Kubernetes e AWS; liderança técnica e duas migrações grandes (monólito para microsserviços, Delphi para Java); inglês.

**O que falta:**

- [ ] Currículo atualizado com a Broadridge e números de impacto
- [ ] IA aplicada em Java (Spring AI, RAG)
- [ ] System design no formato de entrevista
- [ ] Repertório de casos reais de arquitetura para citar nas entrevistas

## Projeto de portfólio

API de comissões orientada a eventos (Java 21, Spring Boot 3, Kafka, PostgreSQL), com um assistente de IA que responde sobre as regras de comissão (Spring AI e RAG). Não usar código de empregadores.

- [ ] Semanas 1 a 4: API, banco de dados, Kafka, outbox e idempotência
- [ ] Semanas 5 a 7: assistente de IA (RAG e tool calling)
- [ ] Semana 8: evals, observabilidade e teste de carga
- [ ] Semanas 12 a 14: README com diagrama, ADRs e artigo publicado
- [ ] Semana 15: um módulo reescrito em Kotlin

## Entrevistas

- **System design** (onde o sênior é aprovado ou não): requisitos, estimativas, API, arquitetura e aprofundamento. Casos: rate limiter, notificações, ledger de pagamentos, pedidos com eventos, busca com RAG e migração de monólito.
- **Comportamental:** 8 histórias STAR com números (ver `historias-star/`).
- **Código:** sem treino diário de algoritmos. Se uma empresa tiver live coding, treinar os padrões mais comuns no NeetCode na semana daquela entrevista. Treinar também corrigir código gerado por IA em voz alta.

## Currículo e LinkedIn

- [ ] 100% em inglês, no máximo 2 páginas, começando pela Broadridge
- [ ] Título: Senior Backend Engineer · Java · AWS & Kubernetes · AI Integration
- [ ] Cada experiência escrita como ação + resultado com número
- [ ] Tirar Delphi, AngularJS e Ionic do destaque
- [ ] LinkedIn com o mesmo título e "Open to work" visível só para recrutadores

## Onde aplicar

- Indicações de ex-colegas: o canal com mais resposta. 2 pedidos por semana.
- LinkedIn com filtro remote/LATAM, mais mensagem direta ao recrutador.
- Plataformas de talento remoto (Arc.dev, Toptal, Turing) e boards europeus (justjoin.it, Djinni).

Na negociação, comparar o valor líquido (não o bruto) e só pedir demissão com a oferta assinada.
