# Projeto de portfólio

API de comissões orientada a eventos (Java 21, Spring Boot 3, Kafka, PostgreSQL), com um assistente de IA que responde sobre as regras de comissão (Spring AI e RAG). Não usar código de empregadores.

- [ ] Semanas 1 a 4: API, banco de dados, Kafka, outbox e idempotência
- [ ] Semanas 5 a 7: assistente de IA (RAG e tool calling)
- [ ] Semana 8: evals, observabilidade e teste de carga
- [ ] Semanas 12 a 14: README com diagrama, ADRs e artigo publicado
- [ ] Semana 15: um módulo reescrito em Kotlin
